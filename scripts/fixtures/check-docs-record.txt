# Cases of the record checks of scripts/check-docs.sh, read by scripts/test-check-docs.sh.
#
# One case per line, five fields separated by ' | ':
#
#   <check> | <pass or fail> | <text the output contains, or -> | <name> | <tree>
#
# The tree is a list of steps separated by '; ', applied in order to a repository that passes
# every check, its setup done: a record of the two ADRs that fill the required roles, accepted,
# OPS:fixture-harness and OPS:fixture-toolchain, and an index with a category list and its two
# tables.
#
#   adr <id> <status>           the ADR file, headed '# <id>: decision', and its index row, in the
#                               table its status belongs to
#   file <id> <status>          the ADR file alone
#   row <table> <id> <status>   an index row alone, in 'binding' or 'archive'
#   status <id> <status>        the status line of the file alone
#   field <id> <name> <text>    a header field of the name with the text, such as Role
#   supersedes <id> <ids>       a Supersedes field linking each id of the comma-separated list;
#                               an id after '+' stands on a continuation line
#   heading <id> <text>         the first line of the file replaced by the text
#   text <file> <text>          a line of text appended to the file
#   category <key>              a project category in the category list of the index
#   blobs                       the blob list docs/adr/NUC.blobs written from the files
#   release <text>              the README's Template release line reading the text
#   setup                       TEMPLATE-SETUP.md present, as before the setup is done
#   commit                      every file committed
#   delete <id>                 the file and its row deleted and committed
#   branch <name>               a new branch, checked out
#   back                        the branch checked out before
#   merge <name>                the branch merged by a merge commit
#
# In the expected text, '<deleted>' stands for the short hash of the commit of the last delete.
#
# An id is '<CAT>:<slug>', the file <CAT>-<slug>.md. A
# status is accepted, proposed, rejected, or superseded:<id>. Everywhere in a line, a colon after
# two to five capital letters, not preceded by a letter, a digit, or '_', and before a letter or a
# digit reads as a hyphen: the file then cites no ADR of this repository, and the map script of the
# normalize skill leaves it as it is.
