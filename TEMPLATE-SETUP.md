# Template setup

This repository is a scaffold. Work through this file to turn it into your own project, then
delete it together with the note that points here from [`README.md`](README.md) and its row in the
README's Project Layout block.

## What only you can do

1. Write your specification in [`docs/SPECIFICATION.md`](docs/SPECIFICATION.md) and record
   structural decisions as ADRs in [`docs/adr/`](docs/adr/).
2. Fill in the **Overview**, **Build, Test & Run**, and **Usage** sections of
   [`README.md`](README.md).
3. Add your language toolchain (the base image ships none).
4. Work through [**Repository settings**](README.md#repository-settings) — the rules that only the
   GitHub repository itself can enforce.

Project-specific conventions belong in the specification and in ADRs — on what may and may not be
edited, see [`AGENTS.md` §3](AGENTS.md#3-adr-rules). Leave the **Dev Container**, **Coding
Agents**, **Repository settings**, and **Project Layout** sections of the README as-is; they
describe the scaffold. The Project Layout block only inventories the files, so a document you
remove goes out of it too — this file included.
